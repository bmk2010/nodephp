Kirish

NodePHP — kichik freymvork bo'lib, bir xil faylda HTML va JavaScript yozish imkonini beradi. Fayl kengaytmasiga .np qo'yiladi, so'rov kelganda esa NodePHP uni o'zi kompilyatsiya qilib, natijani javob sifatida qaytaradi.

Loyihaning asosiy g'oyasi — qurilma zaxirasi (build step), shablon tili va marshrutlash konfiguratsiyasini butunlay olib tashlash. Siz faqat fayl yozasiz, qolganini freymvork hal qiladi.

Nima uchun

  • Bitta fayl, to'liq sahifa. JS mantiqi va HTML yonma-yon — orasida import yoki layout yo'q.
  • Fayl = URL. about.np fayli avtomatik ravishda /about manzilida ishlaydi.
  • Serverless. Vercel'da bitta fayl bilan ishlaydi — maxsus serverning o'zi kerak emas.
  • Bitta bog'liqlik. Faqat express; o'zgartirish uchun hech narsa o'rnatilmaydi.
💡

Qisqacha: NodePHP PHP ning sintaksisidan ilhom olgan, lekin undan butunlay boshqa narsa — u hech qanday kompilyatsiya tilini o'zgartirmaydi, faqat $o'zgaruvchi yozuvini JS ga aylantiradi.

O'rnatish

Node.js 18 yoki yangiroq versiya talab qilinadi.

terminal 
npm install nodephp-js

Global sifatida ishlatmoqchi bo'lsangiz:

terminal 
npm install -g nodephp-js

Tezkor boshlanish

1. Papka yarating

terminal 
mkdir saytim && cd saytim
npm init -y
npm install nodephp-js

2. Birinchi fayl yarating

index.np nomli fayl yarating va ichiga shuni yozing:

index.np 
$ism = "Muhammadhakim";
$sana = "2026";

<html>
  <head>
    <title>$ism — NodePHP</title>
  </head>
  <body>
    <h1>Salom, $ism!</h1>
    <p>Bugun: $sana</p>
  </body>
</html>

3. Serverni ishga tushiring

terminal 
npx nodephp start

Endi brauzerda http://localhost:3000/index.np ni oching.

Sintaksis

NodePHP faylini qator bo'yicha o'qiydi. Har bir qator ikki turdan biriga tushadi: JavaScript yoki HTML.

$ bilan o'zgaruvchilar

$ bilan boshlanuvchi nom — NodePHP o'zgaruvchisi. U ichida JavaScript sintaksisi to'liq ishlaydi: =, +, ==, ===, ?? va h.k.

index.np 
$ism = "Ali";
$yosh = 30;
$arzon = $yosh < 18;

<h1>$ism — $yosh yosh</h1>

if ($arzon) {
  <p>Voyaga yetmagan</p>
} else {
  <p>Kattasiz</p>
}

HTML qatorida $o'zgaruvchi avtomatik ravishda qiymat bilan almashtiriladi. Bu interpolatsiya $config.title kabi xususiyat zanjirlari va $items[0] kabi doimiy indekslarda ham ishlaydi.

JavaScript mantig'i

Qator if, for, while, switch, const kabi kalit so'zlar bilan boshlansa, u JavaScript sifatida bajariladi.

index.np 
$mahsulotlar = [
  { nom: "Olma",  narx: 5000 },
  { nom: "Banan", narx: 8000 }
];

<h1>Mahsulotlar</h1>

for ($i = 0; $i < 2; $i++) {
  $m = $mahsulotlar[$i];
  <div class="mahsulot">
    <b>$m.nom</b> — $m.narx so'm
  </div>
}
🚨

Juda muhim: HTML qatorida o'zgaruvchi bilan indekslash ($items[$i]) ishlamaydi — $i interpolatsiya ichida $items[$i] ko'rinishida qoladi va 500 xato beradi. Yuqoridagi misolda $m = $mahsulotlar[$i]; qatori orqali avval oddiy o'zgaruvchiga o'zlashtirish zarur. Batafsil: Cheklovlar.

Qo'llab-quvvatlanadigan qurilmalar

  • O'zgaruvchi biriktirish va o'zgartirish
  • if / else if / else
  • for, while, do...while
  • switch / case / default
  • try / catch / finally
  • Funksiyalar (ko'p qatorli shaklda)
  • Ko'p qatorli massiv va ob'ekt literallari
  • async / await
  • res, req, console, process

Maxfiylik qoidalari

<?nodephp ... ?> bloklari

Ba'zan qator-asosiy tahlil yetarli bo'lmaydi — masalan oddiy funksiya chaqiruvi yoki murakkab ifoda. Bunday hollarda <?nodephp ... ?> orasidagi hamma narsa sof JavaScript sifatida bajariladi.

index.np 
<?nodephp
const katta = "salom".toUpperCase();
res.write("<b>" + katta + "</b>");
?>

<h1>Keyingi qatorlar yana oddiy HTML</h1>

Blok ichida $o'zgaruvchi ham o'zgaruvchi bo'lib qolveradi, shuning uchun undan tashqarida ham ishlatilishi mumkin.

index.np 
<?nodephp
$mahsulotlar = ["Olma", "Banan", "Nol"];
?>

<ul>
<?nodephp
for (let i = 0; i < $mahsulotlar.length; i++) {
  res.write("<li>" + $mahsulotlar[i] + "</li>");
}
?>
</ul>
⚠️

Blok ichidagi JS satrida ?> belgisini ishlatmang — u blokni muddatidan oldin yopadi. Bunday holatda <?nodephp ishi tamom deb hisoblanadi.

<style> va <script> bloklari

Ularning ichidagi matn o'zgartirilmaydi: interpolatsiya qilinmaydi, kalit so'zlarga qaralmaydi, CSS va JavaScript xom matn sifatida chiqariladi.

index.np 
<style>
  body { font-family: system-ui; color: #111; }
  .btn { padding: 8px 16px; border-radius: 8px; }
</style>

<script>
  let counter = 0;
  function inc() { counter++; document.title = counter; }
</script>

<h1>Salom $ism</h1>
<button class="btn" onclick="inc()">Bosildi</button>

Bitta qatorning o'zida <style> yoki <script> ishga tushsa, qatorning qolgan qismi ham xom chiqariladi va blok </style> / </script> qadar davom etadi.

So'rov ma'lumotlari: file()

file("METOD") — so'rov usuli METOD ga mos kelsa obyekt qaytaradi, aks holda false. Bu eng ko'p ishlatiladigan usul.

index.np 
if (file("POST")) {
  $ism = file("POST").body("ism");
  $parol = file("POST").body("parol");
  <h1>Xush kelibsiz, $ism!</h1>
} else {
  $qidiruv = file("GET").query("q");
  <p>Qidiruv: $qidiruv</p>
}

Metodlar

ChaqiruvQaytaradi
file("POST")obyekt yoki false
.query("kalit")URL query qiymati yoki null
.query()butun query obyekti
.body("kalit")JSON/form tanasidagi qiymat yoki null
.body()butun tana obyekti
.all(){ query, body, headers }

To'liq misol

register.np 
if (!file("POST")) {
  <h1>Ro'yxatdan o'tish</h1>
  <form method="post" action="/register.np">
    <input name="ism" placeholder="Ism">
    <button>Yuborish</button>
  </form>
  kill;
}

$ism = file("POST").body("ism");
$h = file("POST").all().headers;

<h1>Ro'yxatdan o'tdingiz, $ism!</h1>
<p>Manzil: $h["host"]</p>
⚠️

.body() va .query() ni faqat if (file("...")) ichida ishlatish xavfsiz. Aks holda false qiymatning ustiga murojaat qilinadi va 500 xato chiqadi.

Tashqi so'rovlar: connect()

Tashqi manzilga HTTP so'rov yuboradi va { status, ok, data, headers } obyektini qaytaradi. data maydoni Content-Type: application/json bo'lsa avtomatik ravishda obyektga, aks holda matnga aylantiriladi.

api.np 
<?nodephp
const r = connect("https://api.example.com/users", "GET");

res.json({
  status: r.status,
  ok: r.ok,
  ism: r.data.name
});
?>

POST, PUT, PATCH, DELETE

Uchinchi argument JSON body sifatida yuboriladi.

index.np 
<?nodephp
const r = connect("https://api.example.com/users", "POST", {
  ism: "Zafar",
  yosh: 25
});

res.write("Yaratildi: " + r.status);
?>

await kerakmi?

Kerak emas. connect() sinxron ishlaydi — natijani to'g'ridan-to'g'ri olib bo'lasiz. await yozsangiz ham ishlaydi, lekin ortiqcha.

index.np 
<?nodephp
// await yo'q — to'g'ri ishlaydi
const r = connect("https://api.example.com/data");
res.write(r.data.ish);
?>
🚨

O'z serveringizga chaqirmang. connect() chaqiruv paytida Node'ning hodisa siklini to'xtatib turadi. Shu sababli connect("http://localhost:3000/boshqa.np") o'lik turg'unlikka (deadlock) olib keladi va 30 soniyada timeout bilan uziladi. Faqat tashqi manzilarga murojaat qiling.

Qanday ishlaydi

Ichida worker_threads ishlatiladi. Bitta doimiy worker yaratiladi va har chaqiruvda yangi Node jarayoni ochilmaydi — Vercel'da kechikish sezilmaydi. Ma'lumotlar postMessage orqali uzatiladi, shuning uchun qo'shtirnoq, ${...} yoki qiya chiziqlar buzilmaydi. Vaqt chegarasi — 30 soniya.

Fayllar bilan ishlash

readFile(path)

Fayl mazmunini qaytaradi. Fayl topilmasa yoki bo'sh bo'lsa xato tashlaydi.

writeFile(path, data)

Yangi fayl yaratadi yoki mavjud faylni to'liq ustiga yozadi. Argument ob'ekt bo'lsa, avtomatik ravishda JSON sifatida saqlanadi. Muvaffaqiyatda true qaytaradi.

index.np 
<?nodephp
writeFile("ma-lumotlar.json", { kengaytmalar: 12, til: "uz" });

const m = JSON.parse(readFile("ma-lumotlar.json"));
res.write("Kengaytmalar soni: " + m.kengaytmalar);
?>
📁

Yollar process.cwd() ga nisbatan beriladi. Vercel'da filesystem faqat o'qish uchun, shuning uchun ushbu funksiyalar serverless muhitda ishlamaydi — ular lokal server yoki doimiy Node host uchun mo'ljallangan.

Faylni to'xtatish: kill;

Bajarilishni shu nuqtada majburiy to'xtatadi. Keyingi qatorlar umuman bajarilmaydi, javob esa 200 holatida tinch yopiladi.

index.np 
<?nodephp
if (!file("POST")) {
  res.write("<h1>Faqat POST</h1>");
  kill;
}

res.write("bu qator hech qachon chiqmaydi");
?>

Bu marshrutlash uchun qulay: faylning bir qismi 404 yoki redirect qilsa, qolganini o'zgartirish shart emas.

Qanday ishlaydi

Arxitektura atigi uchta qadamdan iborat.

  1. Bloklarga ajratish. Fayl <?nodephp ... ?> bloklari va qolgan "shablon" qismlariga bo'linadi.
  2. Qator bo'yicha tahlil. Har bir qator JavaScript yoki HTML ekani aniqlanadi. Qavs chuqurligi hisoblanib, ko'p qatorli ifodalar to'g'ri aniqlanadi.
  3. Ishga tushirish. Natija AsyncFunction yordamida kompilyatsiya qilinadi va res, file, connect kabi o'zgaruvchilar parametrlar sifatida beriladi.

Quyidagi kod uz.html dagi birinchi namunaga aynan mos keladi:

transpile natijasi 
var_ism = "Muhammadhakim";
var_sana = "2026";
  if (!res.writableEnded) { res.write(`<html>
`); }
  if (!res.writableEnded) { res.write(`  <head>
`); }
  if (!res.writableEnded) { res.write(`    <title>${var_ism} — NodePHP</title>
`); }

Ko'rib turganingizdek, $ism var_ism ga aylangan va HTML qatorlari res.write() ga o'ralgan. Bu butun transpilyatsiya.

Nima uchun bunday

  • Sodda. Bitta o'tish, tashqi bog'liqliksiz, o'rganish oson.
  • Tez. Barcha mantiq bir AsyncFunction da bajariladi — qo'shimcha qatlam yo'q.
  • Xavfsizroq. HTML matni avval to'liq interpolatsiya qilinadi, keyin shablon literali sifatida chiqariladi; $, backtick va \ avtomatik himoya qilinadi.

Cheklovlar

Bu ro'yxat amaliy sinovlarda aniqlangan, real muammolar. Ularni bilish kerak.

1. HTML ichida o'zgaruvchi bilan indekslash

Eng ko'p uchraydigan muammo. HTML qatorida $items[$i] yozilsa, $i interpolatsiya ichida qoladi va SyntaxError beradi.

✗ ishlamaydi 
$items = ["Olma", "Banan"];
for ($i = 0; $i < 2; $i++) {
  <li>$items[$i]</li>      <- 500 SyntaxError
}
✓ to'g'ri 
$items = ["Olma", "Banan"];
for ($i = 0; $i < 2; $i++) {
  $item = $items[$i];            <- avval oddiy o'zgaruvchiga
  <li>$item</li>              <- HTML toza
}

Yoki butun tsiklni <?nodephp ?> blokiga ko'chiring — u yerda o'zgaruvchi bilan indekslash bezuvaq ishlaydi.

2. HTML bir qatorli JS bilan aralashmasin

✗ ishlamaydi 
if ($x) { <p>ha</p> }

HTML teglar har doim alohida qatorga yozilishi kerak.

3. // izoh va qavsli qatorlar

Qator tahlilida // izohlar avval tozalanadi. Shu sababli connect("https://...") kabi qator (qavs + //) keyingi HTML qatorining holatini buzishi mumkin. Yechim: chaqiruvdan keyin bo'sh qator qo'ying yoki <?nodephp ?> blokidan foydalaning.

4. require va import ishlamaydi

.np fayl AsyncFunction tanasi sifatida ishga tushadi. Unda require va import mavjud emas — ular 500 xato beradi. Node moduli kerak bo'lsa, process, fetch va connect() dan foydalaning. await import(...) esa ishlaydi.

5. HTML rejimida funksiya chaqirilmaydi

function salom($i) { ... } yozilgan qatordan keyingi salom("Ali"); qatori HTML deb hisoblanadi va matn sifatida chiqadi. Chaqiruvni <?nodephp ?> blokiga yoki JS qatoriga joylashtiring.

6. connect() hodisa siklini bloklaydi

Sinxron ishlashi sababli boshqa so'rovlar javob bermay turadi. Bir xil server ichidagi faylga murojaat qilmang.

7. Kompilyatsiya keshi yo'q

Har bir so'rovda fayl qayta o'qiladi va qayta kompilyatsiya qilinadi. Bu kichik saytlar uchun yetarli, lekin katta trafik uchun kutilgan narsa emas.

FAQ

JQuery ishlatib bo'ladimi?

Yo'q. $ har doim NodePHP o'zgaruvchisi deb hisoblanadi. Agar JavaScript ichida jQuery kerak bo'lsa, uni <script> blokida yuklang — u xom chiqariladi.

Narxni $5.00 shaklida yozsa bo'ladimi?

Ha. $ dan keyin raqam kelsa, u o'zgaruvchi emas deb hisoblanadi va xom matn qoladi.

Markdown yoki JSX ishlatib bo'ladimi?

Yo'q. NodePHP faqat oddiy HTML va JavaScript bilan ishlaydi. Markdown kerak bo'lsa, build bosqichida avval HTML'ga aylantiring.

Ma'lumotlar bazasi bilan ishlasa bo'ladimi?

To'g'ridan-to'g'ri import yo'qligi sababli — yo'q. Ammo connect() yordamida REST API orqali har qanday tashqi xizmatga ulanishingiz mumkin.

Natijani keshlashtirsam bo'ladimi?

Ha, res.setHeader("Cache-Control", "max-age=600") yozish yetarli. Kompilyatsiya keshi esa ichki darajada yo'q.

Boshqa Node loyihasi bilan birga ishlay oladimi?

Ha. executeNodePHP va transpileNodePHP eksport qilingan — nodephp-js/lib/engine.js dan import qilib ishlatishingiz mumkin.
